# 📥 محمل الفيديو - Video Downloader

تطبيق ويب بسيط وسهل الاستخدام لتحميل الفيديو من منصات متعددة

## 🌟 المميزات

- ✅ دعم عدة منصات (YouTube, TikTok, Instagram, Facebook, Twitter/X)
- 🎯 واجهة عربية سهلة الاستخدام
- 📱 تصميم متجاوب يعمل على جميع الأجهزة
- 🎨 واجهة حديثة وجميلة
- ⚡ سريع وخفيف الوزن
- 🔍 اكتشاف تلقائي للمنصة من الرابط
- 🎬 خيارات جودة متعددة
- 🔊 تحميل الصوت فقط

## 🚀 المنصات المدعومة

| المنصة | مثال على الرابط | الحالة |
|--------|-----------------|--------|
| YouTube | https://www.youtube.com/watch?v=xxx | ✅ مدعومة |
| TikTok | https://www.tiktok.com/@user/video/xxx | ✅ مدعومة |
| Instagram | https://www.instagram.com/p/xxx | ✅ مدعومة |
| Facebook | https://www.facebook.com/.../video/xxx | ✅ مدعومة |
| Twitter/X | https://twitter.com/user/status/xxx | ✅ مدعومة |

## 📋 المتطلبات

- متصفح ويب حديث (Chrome, Firefox, Safari, Edge)
- اتصال بالإنترنت

## 🛠️ التثبيت والتشغيل

### الطريقة 1: المحلي

```bash
# استنساخ المستودع
git clone https://github.com/waelzarzoor/video-downloader.git

# الانتقال إلى المجلد
cd video-downloader

# فتح الملف في المتصفح
# يمكنك فتح index.html مباشرة في المتصفح
# أو استخدام خادم محلي:

python -m http.server 8000
# ثم افتح http://localhost:8000
```

### الطريقة 2: عبر الويب

قريباً - سيتم نشر الموقع على خادم ويب

## 🎯 طريقة الاستخدام

1. **أدخل الرابط**: الصق رابط الفيديو في حقل الإدخال
2. **اضغط تحميل**: اضغط على زر "تحميل الفيديو"
3. **اختر الجودة**: اختر الجودة المفضلة من الخيارات
4. **احفظ الملف**: احفظ الملف على جهازك
